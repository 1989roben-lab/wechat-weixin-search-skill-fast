# WeChat / Weixin Search Skill Fast

一个为 Codex 打造的 **微信公众号快速搜索 Skill**。  
它把微信生态里最难用的“公众号文章搜索”包装成一个轻快、可控、适合日常研究的工作流：输入公司名或主题，几秒内拿到标题、日期、命中关键词和参考链接。

## 为什么用它

微信公众号搜索经常慢、散、结果混杂，还容易被长链接拖垮阅读体验。这个 Skill 的目标很简单：

- **快**：并行搜索多个关键词，实测常见公司查询约 3 秒返回结果。
- **准**：围绕公司名 + 主题词组合搜索，减少泛关键词噪声。
- **可筛选**：支持排除招聘、培训、无关品牌、同名产品等干扰项。
- **可匹配**：自动保留命中关键词，方便判断结果来自 AI、云、出海、安全、算力、CDN 等哪个方向。
- **干净输出**：先给结果表，最后集中附链接，不让超长搜狗链接打断阅读。
- **可扩展**：默认走快速搜索，需要深挖时再对少数高价值文章解析原文或正文。

## 适合哪些场景

- 客户拜访前，快速查某家公司在微信公众号上的近期动态。
- 找行业新闻、竞品动态、产品发布、活动信息、生态合作。
- 搜索 AI、云计算、出海、安全、边缘云、CDN、数据库等主题下的公众号文章。
- 把公众号搜索结果整理成简洁表格，方便继续做客户研究、销售准备、市场分析或内部分享。

## 使用方式

在 Codex 里可以直接说：

```text
用 wechat-weixin-search-skill-fast 搜索网宿科技的微信公众号新闻，返回10条。
```

也可以更具体：

```text
搜索白山云在微信公众号上的最新新闻，排除白山一云、矿泉水、招聘，优先看 AI、边缘云、安全、算力。
```

推荐提示词：

```text
用 wechat-weixin-search-skill-fast 搜索【公司名】的微信公众号新闻，返回10条。
要求：
1. 5秒内先返回标题、日期、命中关键词
2. 最后集中附参考链接
3. 排除招聘、培训、无关品牌
4. 优先关注【你关心的主题词】
```

## 速度从哪里来

这个 Skill 默认采用快速模式：

- 多关键词并行请求。
- 不在第一轮逐条解析真实 `mp.weixin.qq.com` 链接。
- 不在表格中铺开超长链接。
- 请求超时默认较短，避免单个慢请求拖住整轮搜索。

如果你需要全文精读，可以先让 Skill 快速筛出 10 条，再只挑 2-3 条高价值结果做慢速解析。

## 依赖

本 Skill 依赖本地已安装的 `weixin_search` MCP / `weixin-search-mcp`：

```bash
pip install weixin-search-mcp
```

在 Codex 中建议配置为本地 MCP，并使用 `weixin_company_news` 快速聚合工具。

## 注意

- 搜索结果来自搜狗微信索引，不是微信官方全量搜索 API。
- 参考链接默认是 `weixin.sogou.com/link?...` 跳转链接，不等于已解析的公众号原文链接。
- 真实原文链接和正文内容解析会更慢，建议只对精选结果做二次处理。
